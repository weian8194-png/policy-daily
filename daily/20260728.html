平台政策

紧急 Amazon 亚马逊标题75字符新规7/27全面落地执行

2026年7月27日，亚马逊标题75字符新规正式生效。除媒体类商品外，全品类标题必须≤75字符（含空格），超长标题由系统AI逐步改写，同步上线125字符Item Highlights承接卖点关键词。品牌备案卖家享14天审核窗口，白牌卖家直接截断。各大卖家圈反馈分化：有人改完销量翻倍，有人改完标题刷不出来。

生效时间2026年7月27日（已生效）
影响范围全站点非影音类商品
信息来源Amazon / 卖家之家 / 出海网
🎯 3步行动清单
  1. 立即导出所有ASIN标题长度，优先优化超75字符高销量ASIN
  2. 将溢出关键词转移至Item Highlights 125字符字段
  3. 14天审核窗口内逐条审核AI改写方案，确保核心卖点不丢失
紧急 Amazon 亚马逊全站点集中清退凝胶捏捏乐

大批亚马逊卖家收到产品永久停用通知，含流体/凝胶填充的捏捏乐开启全域清查，覆盖美国、欧洲五国、加拿大站点。链接永久下架无法恢复，未履约订单自动取消，FBA库存需60天内移仓逾期销毁。起因英国监管抽检多款捏捏乐苯含量超标(最高20mg/kg)，即便持有CPC证书，通用套证/模板报告平台不予认可。平台同步启动高风险连坐机制，玩具类目合规持续收紧。

生效时间执行中（7月持续）
影响范围美国/欧洲五国/加拿大 全站点
信息来源Amazon / 亿恩网 / 出海网 / 网经社
🎯 3步行动清单
  1. 立即盘点店铺内所有凝胶/液体填充解压玩具库存
  2. 60天内完成FBA库存移仓，避免逾期销毁产生额外费用
  3. 玩具类产品合规必须做到证书与实物匹配，通用套证不可靠
紧急 FTC Amazon FTC $25亿和解案7/27索赔截止

FTC与亚马逊达成的$25亿和解案7/27正式截止索赔，Prime非自愿注册/退订受阻用户最高可获$51退款，逾期未申请视为放弃。该和解案同时确立了订阅模式透明度合规标准：明确条款披露+知情同意机制+一键取消系统，影响所有在亚马逊平台运营订阅服务的第三方卖家，预估15-25%运营订阅服务的卖家缺乏合规文档机制。

截止时间2026年7月27日（已截止）
影响范围所有运营订阅模式的亚马逊第三方卖家
信息来源FTC / yayanews.ai

  1. 确认是否运营订阅服务（订阅盒/定期配送/会员计划），自查合规缺口
  2. 实施明确条款披露+知情同意机制+一键取消系统

合规/税务动态

紧急 CBP CBP临时指令：8/1起CNC/精密设备进口须附数字原产地声明+能效声明

CBP于7/27发布临时指令，自8月1日起，所有进口美国的CNC机床、精密加工设备及自动化产线核心零部件须随附两份文件：认证数字原产地声明(DOS)和IEC 62443-4-2兼容能效声明。不符合要求的货物将面临扣港、退运或额外15%合规附加费。该要求直接影响清关时效、文件准备和合规成本。

生效时间2026年8月1日
影响范围CNC机床/精密加工设备/自动化产线核心零部件进口商
信息来源CBP / ynypm.com
🎯 3步行动清单
  1. 确认产品是否涉及CNC/精密设备/自动化核心零部件
  2. 准备数字原产地声明(DOS)认证文件+IEC 62443-4-2兼容能效声明
  3. 评估15%合规附加费风险，提前调整清关流程和成本预算
关注 eBay eBay海外仓新规7/27正式执行

eBay《认证对接仓使用率要求》7/27正式在卖家中心更新。核心变化：2025/1/1后开通海外仓资质的企业卖家，所有海外仓订单纳入使用率考核；新入驻企业卖家强制使用平台认证对接仓，12个月300笔门槛；非认证仓或取消海外仓销售权限。

生效时间2026年7月27日（已生效）
影响范围所有使用eBay海外仓的企业卖家
信息来源eBay / 卖家之家 / 出海网
🎯 3步行动清单
  1. 确认当前使用的海外仓是否为平台认证对接仓
  2. 核查12个月内海外仓订单使用率是否达标（300笔门槛）
  3. 非认证仓卖家尽快切换至认证仓，避免销售权限被取消
关注 TEMU Temu强制中国卖家产品责任险备案

Temu正式对入驻中国跨境卖家推出产品责任险强制备案规则。所有入驻北美/欧洲站点的中国企业主体卖家，上架带电产品、家居用品、母婴玩具等品类必须提前上传COI凭证。核心要求：单次事故最低赔付100万美元、被保险人须与入驻主体一致、拼多多Temu及其关联公司须列为附加被保险人、每个独立店铺须单独对应保单。同步Wayfair/HomeDepot/Walmart/Chewy等平台也陆续更新保险核验机制。

生效时间执行中
影响范围所有Temu北美/欧洲站中国卖家
信息来源TEMU / 头条号
🎯 3步行动清单
  1. 确认店铺品类是否在强制投保范围内（带电/家居/母婴/户外/厨房）
  2. 准备单次事故100万美元+保额的产品责任险，被保险人与入驻主体一致
  3. 多店铺矩阵运营卖家须为每个独立店铺单独投保
关注 Amazon Tax 波兰捷克VAT注册合规升级

亚马逊中欧计划(CEE)卖家注意：库存调拨到波兰/捷克仓即触发VAT注册义务，即使没有当地订单。需同时提供波兰和捷克VIES增值税号。波兰VAT注册约1-2个月，捷克2-3个月。无法提供VAT者被按第三国卖家处理，亚马逊代缴VAT，卖家可能面临双重缴税风险。

生效时间执行中
影响范围所有开启中欧计划的亚马逊欧洲站卖家
信息来源Amazon / 卖家之家
🎯 3步行动清单
  1. 进入卖家平台→设置→FBA→跨境物流设置→库存仓储国家，检查是否开启中欧计划
  2. 若包含波兰或捷克，立即启动VAT注册（波兰1-2月/捷克2-3月）
  3. 注册期间向亚马逊提交VAT-IDN验证，避免被按第三国卖家代缴VAT
关注 商标法 新《商标法》2027/1/1生效 打击恶意抢注

新修订的《中华人民共和国商标法》已于2026年6月26日通过，自2027年1月1日起施行。全文9章87条，核心变化：强调真实经营背景与实际使用、打击按Best Seller榜单批量抢注的"商标刺客"、强化商标代理规范。此前抢注者照着亚马逊Best Seller批量注册国内商标后向原卖家索要高价转让费，甚至通过海关拦截出口货物施压。新法有望缓解跨境卖家海外商标被国内抢注的痛点。

生效时间2027年1月1日
影响范围所有跨境出海品牌卖家
信息来源国家知识产权局 / 163.com
🎯 3步行动清单
  1. 排查自有品牌商标是否已被国内抢注，如有可关注新法救济途径
  2. 2027/1/1前完善商标注册真实经营背景和实际使用证据
  3. 关注新法施行后的具体实施细则和执法力度
关注 CPSC CPSC启动急诊室伤害数据采集计划

CPSC宣布启动新倡议，与医院和医疗机构合作系统性采集消费品相关的急诊室伤害数据。该计划从传统的被动报告模式转向实时数据驱动的安全监管，旨在更精准识别伤害模式、更快速实施针对性召回和安全警告。对制造商而言，合规审查将更加频繁和深入，产品安全标准可能进一步提升。

启动时间2026年7月28日
影响范围所有消费品制造商和进口商
信息来源CPSC / caregiversupportnetwork.org
🎯 3步行动清单
  1. 评估现有产品安全测试和合规文档是否满足可能升级的审查标准
  2. 建立内部伤害数据追踪机制，主动识别潜在安全风险
  3. 关注CPSC后续发布的具体数据采集范围和产品类别清单
